# Приёмка сдачи

Отчёт исполнителя доказывает, что работает у него. Приёмка доказывает, что работает у тебя.

## Шаги

1. **Что сдано на самом деле.** Сверить разделы файла задач / PR с резюме исполнителя.
   Сделана ли каждая задача очереди, или он пропустил дописанную позже.
2. **Состав.** `git log origin/main..<hash>` — только коммиты задачи; `git diff --stat` —
   только её файлы. Коммит стоит на свежем main (иначе rebase, и гейт после rebase).
3. **Гейт на чистой копии.** `git worktree add --detach <tmp> <hash>`, зависимости по lock-файлу
   среза, своя одноразовая база с `test` в имени, команды проекта (lint, типы, все тесты с
   интеграцией). Число пропусков — отдельно: «всё skipped» = красное.
4. **Порча.** Откатить к базе только НЕ-тестовые файлы задачи → названные пробы красные, с
   именами. Если откат удаляет модуль, от которого зависят пробы (длинная ветка), — точечный
   откат одного файла или мутация условия (`x !== "optional"` убрать). Вернуть → зелёные.
5. **Дифф глазами по фронтам:**
   - безопасность: роль проверяется до разбора тела, область видимости, IDOR;
   - данные: миграции, удаление, заполнение, личные данные в журналах;
   - контракт: новое поле/код ошибки — не отвергнет ли соседний сервис весь ответ;
   - выкат и сервер: запись на сервер атомарная (`.new` → `chmod` → `mv`), без `--delete` и масок,
     `.env` и конфиги не задеты; проверка до шага, который её чинит, не блокирует сам шаг;
   - новая проверка зарегистрирована там, где её запускают (CI-файл, список предполёта);
   - интерфейс: скилл `ux-ui-review` — сверка с макетом и словарём, все языки, 390 и 1440 без
     прокрутки вбок, консоль чистая, сценарий пройден в браузере другой ролью; находка — при ≥2 голосах;
   - мёртвые охранники: `[ -n "$(… | shasum)" ]` не срабатывает никогда (пустой ввод даёт
     непустой отпечаток).
6. **Итог** — в файл задач и владельцу:
   - `ПРИНЯТА`: хеш, гейт (passed/failed/skipped), порча (сколько красных без правки);
   - `ВОЗВРАТ`: задача Nb с пунктами блокер / мелочь / ответ.
7. **Уборка:** временная выкладка и база снесены, браузеры закрыты — проверено перечитыванием.

## После приёмки

rebase → гейт на перебазированном → push → предпроверка окружения → замок выката → выкат →
проверка на бою тем путём, каким пойдёт пользователь → строка соседям «выкат закончен» →
строка владельцу постфактум.

## Чего не делать

- Не принимать по зелёному отчёту без своего прогона.
- Не чинить найденное самому, если есть исполнитель, — возврат.
- Не мерить в выкладке исполнителя: она может двигаться под тобой.
