# Шаблон задачи исполнителю

Задача, по которой исполнитель не может сделать работу без вопросов, — плохая задача.
Каждое поле отвечает на вопрос, который иначе он решит сам и неправильно.

## Шапка файла очереди

```json
{
  "pm": "постановка и приёмка: PM, по коду, тестам, своему гейту и порче",
  "accepted": {"1": "a1b2c3d — на бою", "2": "ВОЗВРАТ: задача 2b"},
  "order": ["2b", "3"],
  "reread": "перед каждой задачей перечитай её раздел: PM дописывает уточнения",
  "lessons": ["урок, из-за которого был возврат, — одной строкой"],
  "env": {"db": "как завести свою базу", "disk": "что делать при нехватке места"},
  "rules": [
    "только своя выкладка; без push, выката, сервера, секретов, .env, --no-verify",
    "минимум кода, хирургично: каждая строка к задаче; чужое не рефакторить",
    "комментарии объясняют «почему»; коммиты атомарные",
    "перед коммитом git status: в коммите только файлы задачи",
    "порча: сломай условие → проба красная → верни ПРАВКОЙ, не git checkout",
    "спека спорит с кодом — стоп, в questions"
  ],
  "report": {"commits": [], "files": [], "gate": {"cmd": "", "exit": 0, "passed": 0, "failed": 0, "skipped": 0},
             "mutations": [{"what": "", "red_tests": [], "restored_green": true}], "decisions": [], "questions": []}
}
```

## Раздел задачи

```json
{
  "worktree": "точная команда git worktree add … origin/main (и от какого коммита не раньше)",
  "why": "что сломано или нужно, с фактом: где видно, когда случилось",
  "rule": "правило, которое должно стать правдой, одной фразой",
  "steps": ["шаги, если путь важен; иначе опустить"],
  "tests_required": ["какие пробы обязаны появиться, включая положительную опору"],
  "mutations_required": ["что сломать → какая проба обязана покраснеть"],
  "gate": "точная команда гейта и что допустимо красным (с причиной)",
  "not_now": ["что явно НЕ делать в этой задаче"],
  "report_section": "Отчёт · задача N"
}
```

## Возврат на доработку (задача Nb)

```json
{
  "worktree": "та же выкладка, новые коммиты поверх, без amend",
  "pm_gate_on_<hash>": "что принято и чем проверено",
  "fix": [
    "1 [БЛОКЕР] что не так → чем грозит → РЕШЕНИЕ PM, если была развилка",
    "2 [мелочь] …",
    "3 [ответ на твой вопрос] …"
  ],
  "tests_required": [], "mutations_required": [], "gate": "", "report_section": "Отчёт · задача Nb"
}
```

## Проверка задачи перед отправкой

- [ ] Выкладка от свежего main, и сказано, от какого коммита не раньше.
- [ ] Есть факт «почему», а не пересказ.
- [ ] Спорное решено PM заранее или прямо названо вопросом.
- [ ] Порча названа: без неё зелёный гейт ничего не доказывает.
- [ ] Сказано, чего не трогать (сервер, выкат, соседние модули).
- [ ] Новая проверка — сказано, где её зарегистрировать, чтобы её запускали.
