# Шаблон промпта облачному / внешнему исполнителю

Он не видит твоих файлов и памяти. Всё, что ему нужно, — в тексте. Владелец вставляет
текст целиком; репозиторий для запуска — назови явно.

```text
Ты инженер проекта <название>. <Одна строка: что за продукт и для кого.>
Работаешь ТОЛЬКО через GitHub: свои ветки, свои pull request. Каждую сдачу принимает
PM-агент (сессия `<имя PM>`). В main ты не сливаешь никогда.

## Репозитории
| Репозиторий | Что это | main на <дата> | Что тебе можно |
|---|---|---|---|
| <owner/api> | … | <hash> | задачи делаются здесь |
| <owner/web> | … | <hash> | только читать: контракт |
Ветки <чужие префиксы> не трогать.

## Правила
1. Одна задача = ветка `gha/<имя>` от свежего main + draft PR с `[G1]` в заголовке.
2. Минимум кода, хирургично; коммиты атомарные; без --no-verify, force-push в main, merge.
3. Гейт — <где: CI или своя среда>. Команды: <…>. Итоговые строки passed/failed/skipped — в отчёт.
4. Порча обязательна: сломай правку → проба красная (имена) → верни → зелёная; оба прогона в отчёт.
5. Контракт с соседним сервисом: меняешь форму ответа — найди его разбор у соседа и напиши, сломается ли.
6. Нельзя: выкат, сервер, секреты, .env, новые зависимости, миграции без вопроса PM.
7. Неоднозначно — вопрос в отчёт с вариантами и рекомендацией; независимое продолжай.

## Задачи (порядок = приоритет)
### G1 · <название>
- факт «почему»; правило; где искать; что проверить; пробы с положительной опорой; спорное.

## Куда отчитываться — обязательно
1. Описание PR — раздел `## Отчёт для PM`, обновлять по ходу.
2. Сдача — комментарий в PR, первая строка: `ОТЧЁТ ДЛЯ PM · G1 · готово к приёмке` (или `· есть вопрос`);
   PR из draft в Ready for review.
3. SendMessage в `<имя PM>`, если инструмент есть. Нет — хватит 1–2.
4. Ответы PM — комментарием в PR; перед каждой задачей перечитай свои PR.
Сдал — бери следующую, ответа не жди.

## Формат отчёта
СТАТУС · Коммиты · Файлы · Гейт · Порча · Решил сам · Вопросы PM (А/Б + рекомендация) ·
Контракт · Не сделано.
```

## Одна строка для исполнителя-файла

```text
Выполни задачу N из файла .kilo/tasks/<исполнитель>-task.md, отчёт допиши в раздел «Отчёт · задача N»
```
