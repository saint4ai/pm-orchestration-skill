# Грабли, на которые уже наступали

Каждая строка — реальный случай. Прочитай перед первой партией и первым выкатом.

| Момент | Что случилось | Правило |
|---|---|---|
| Приёмка | исполнитель сдал «задачи 4 и 5», а срочную 3c, дописанную позже, не увидел | сверять сделанное по разделам файла, а не по резюме |
| Приёмка | новая проверка добавлена, но не вписана туда, где её запускают, — предполёт выката красный. Дважды подряд | в задаче прямо писать «зарегистрируй проверку там-то»; в приёмке — отдельный пункт |
| Приёмка | откат «всех не-тестовых файлов» к main удалил целый модуль длинной ветки — порча недействительна | точечный откат одного файла или мутация условия |
| Приёмка | зелёная проба без правки | принимать только с красным прогоном без правки |
| Сервер | скрипты сервера поставили вручную, а список «известных расхождений» не поправили — выкат встал на сверке | поставил на сервер — тем же заходом обнови все копии и список, прогони сверку |
| Сервер | перенос скрипта `scp` поверх файла, который cron запускает каждые 5 минут | `.new` → `chmod` → `mv`: bash читает скрипт по ходу исполнения |
| Выкат | проверка расхождений стоит ДО шага, который их устраняет, — шаг не наступит никогда | для файлов, которые выкат сам везёт, побеждает main; стоп только на чужих |
| Машина | соседняя сессия-чистильщик удалила браузеры проб за 15 минут до выката — 13 из 27 боевых проб упали | до выката — строка владельцу общего ресурса; кэши проб в исключения |
| Машина | диск «кончился» без видимых файлов: macOS готовила обновление на закрытом томе | снимки обновления = подозреваемый №1; решение — владельцу |
| Машина | Docker Desktop держал ~12 ГБ памяти, подкачка съедала диск | выключить Docker на время — с предупреждением владельцев контейнеров |
| Связь | адрес соседа по сокету протух после его перезапуска | писать по имени из `ListAgents` |
| Связь | облачный агент «отчитается через SendMessage» — не может | канал обратно — PR на GitHub |
| CI | промпт требовал «зелёный CI», а Actions не запускались неделю (оплата) | проверить `gh run list` до промпта; владелец может не хотеть платить за CI — тогда гейт в среде исполнителя |
| Лимит | PM сам чинил строки и мониторил журналы — лимит кончился | код и починки — исполнителям; PM читает только итоговые строки журналов |
| Бой | повтор боевых проб подряд упёрся в предел входов | окно входов — ресурс; повтор планировать, а не жать |
| Владелец | отчёт на жаргоне — владелец потратил заход на расшифровку | без терминов или с объяснением на пальцах |
